# MNIST Digit Classification: ANN, CNN, and RNN

A hands-on deep learning project exploring how Artificial Neural Networks (ANNs), Convolutional Neural Networks (CNNs), and Recurrent Neural Networks (RNNs) classify handwritten digits from the MNIST dataset.

This project was completed as part of my deep learning study, following the Sheryians AI School series. I used it to practice image preprocessing, model training, and comparing different neural network architectures on the same task.

## Models

- ANN
- CNN
- RNN

## Tools

- Python
- TensorFlow / Keras
- Google Colab

## Run the notebook

Open `mnist_ann_cnn_rnn.ipynb` in Google Colab and run the cells in order. The notebook contains the data preparation, model training, and evaluation steps.
